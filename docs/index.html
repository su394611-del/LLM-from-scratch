Transformer From Scratch Using PyTorch

An educational implementation of a Transformer encoder for sentiment classification with PyTorch.

Project Features

  • Multi-head self-attention
  • Query, Key, and Value projections
  • Sinusoidal positional encoding
  • Transformer encoder layers
  • GELU feed-forward networks
  • Residual connections and LayerNorm
  • Masked mean pooling
  • Binary sentiment classification
  • AdamW optimization
  • CPU and CUDA training support

Training Modes

Includes an offline smoke test and Yelp review classification experiments. Real-data experiments use a pretrained tokenizer and frozen token embeddings.
